FIX: COURSE PROGRESS NOT UPDATING AFTER MODULE COMPLETION
Date: November 11, 2025
Time: Current Session (Follow-up to Slug Fix)
================================================================================

ISSUE:
------
After completing a module, the course progress displayed 0% with 0/0 XP earned
even though the module showed as completed (with checkmark and XP awarded).

This prevented the progress indicator from updating after successful completions.

ROOT CAUSE:
-----------
The course page was not refreshing the composable data after module completion:

1. VCodePlayground component clears the Nuxt cache when a module is completed
2. BUT the cache clearing alone doesn't trigger a re-fetch
3. The composables have a `refresh()` function that needed to be called
4. The course pages were not storing or calling this refresh function

The flow was broken:
  Module completion → Cache cleared → Data NOT re-fetched → UI stays stale

SOLUTION:
---------

STEP 1: Extract Refresh Functions from Composables
---------------------------------------------------
Updated all course pages to store the `refresh` function from composables:

```typescript
// Before:
const { progress: courseProgressData } = useCourseProgress("python");

// After:
const { progress: courseProgressData, refresh: refreshProgress } = useCourseProgress("python");
const { completedExternalIds, isModuleCompleted, refresh: refreshCompletions } = useCourseCompletions("python");
```

STEP 2: Create Refresh Handler
------------------------------
Added a handler to refresh both composables when module tests pass:

```typescript
const onModuleTestsPassed = async () => {
  console.log('[course] Module tests passed, refreshing progress...');
  await refreshProgress();
  await refreshCompletions();
};
```

STEP 3: Connect Event Handler to VCodePlayground
-------------------------------------------------
Bound the handler to the component's @all-tests-passed event:

```vue
<VCodePlayground
  :exercise="activeModule.exercise"
  :module-id="activeModule.id"
  :module-difficulty="activeModule.difficulty"
  :module-title="activeModule.title"
  @all-tests-passed="onModuleTestsPassed"
/>
```

FILES MODIFIED:
---------------
All 7 course pages updated with same pattern:

1. front-end/pages/courses/python/index.vue ✓
2. front-end/pages/courses/machine-learning/index.vue ✓
3. front-end/pages/courses/deep-learning/index.vue ✓
4. front-end/pages/courses/llm-engineering/index.vue ✓
5. front-end/pages/courses/rag/index.vue ✓
6. front-end/pages/courses/agentic-ai/index.vue ✓
7. front-end/pages/courses/mcp/index.vue ✓

HOW IT WORKS NOW:
-----------------
1. User completes module exercises and clicks "Run tests"
2. All tests pass → VCodePlayground awards XP
3. VCodePlayground emits @all-tests-passed event
4. Course page's onModuleTestsPassed handler fires
5. Handler calls refreshProgress() and refreshCompletions()
6. Composables clear their cache and re-fetch fresh data
7. UI updates with new progress immediately

DATA FLOW:
----------
Module Completion (in VCodePlayground):
  ↓
Cache cleared: `clearNuxtData('course-progress:${courseSlug}')`
  ↓
@all-tests-passed event emitted
  ↓
Course page listener receives event
  ↓
onModuleTestsPassed() handler executes
  ↓
refresh() functions called on both composables
  ↓
Composables clear cache and call refreshData()
  ↓
Fresh API calls to /api/courses/{slug}/progress and .../completions
  ↓
Supabase queries return latest completion data
  ↓
UI computed properties trigger reactively update
  ↓
Progress bar, XP count, and module list all reflect new state

VERIFIED:
---------
✅ All 7 course pages updated consistently
✅ Event handlers properly typed and connected
✅ Refresh functions await properly (async flow)
✅ Cache invalidation and re-fetch work together
✅ No linting errors introduced

RESULT:
-------
✅ Progress now updates immediately after module completion
✅ XP counter reflects earned points in real-time
✅ Module checkmarks appear correctly
✅ Progress bar percentage increases as expected
✅ Completion indicator shows correct status

LESSON LEARNED:
---------------
- Cache clearing alone is not enough for reactive updates
- Must also call the composable's refresh() function
- Events provide the communication bridge between components
- Async refresh operations must be properly awaited

FIX: DAILY STREAK MODULE SUBMISSION 404 ERROR
Date: November 11, 2025
Time: Current Session (Follow-up to Progress Fix)
================================================================================

ERROR:
------
POST http://localhost:3000/api/exercises/submit 404 (Module not found for external_id: daily-streak-3)

When submitting code in the daily-streak page, the /api/exercises/submit endpoint
was looking for a module with external_id "daily-streak-3" and failing with 404.

ROOT CAUSE:
-----------
VCodePlayground component was checking for the wrong prefix:

1. Daily-streak page passes moduleId: `daily-streak-${day}` (e.g., "daily-streak-3")
2. VCodePlayground checks for `daily-challenge-` prefix ONLY
3. Check failed → falls through to regular module submission logic
4. /api/exercises/submit tries to find module with external_id "daily-streak-3"
5. No such module exists in database → 404 error

SOLUTION:
---------
Updated VCodePlayground to recognize both daily challenge prefixes:

BEFORE:
```typescript
const isDailyChallenge = String(moduleIdentifier).startsWith("daily-challenge-");
if (isDailyChallenge) {
  const challengeId = String(moduleIdentifier).replace("daily-challenge-", "");
  // ... call /api/daily-challenge/complete
}
```

AFTER:
```typescript
const isDailyChallenge = String(moduleIdentifier).startsWith("daily-streak-") || 
                         String(moduleIdentifier).startsWith("daily-challenge-");
if (isDailyChallenge) {
  let challengeId = String(moduleIdentifier);
  if (challengeId.startsWith("daily-streak-")) {
    challengeId = challengeId.replace("daily-streak-", "");
  } else if (challengeId.startsWith("daily-challenge-")) {
    challengeId = challengeId.replace("daily-challenge-", "");
  }
  // ... call /api/daily-challenge/complete
}
```

FILES MODIFIED:
---------------
front-end/components/organisms/VCodePlayground.vue
  - Lines 213-223: Added support for "daily-streak-" prefix
  - Maintains backward compatibility with "daily-challenge-" prefix

HOW IT WORKS NOW:
-----------------
1. Daily-streak page loads with moduleId "daily-streak-3"
2. User completes the challenge and clicks "Run tests"
3. VCodePlayground.submitCompletion() is called
4. Component checks if moduleId starts with "daily-streak-" or "daily-challenge-"
5. Prefix detected → extract challenge ID "3"
6. Call /api/daily-challenge/complete with challengeId: "3"
7. Backend successfully completes the daily challenge
8. XP awarded and challenge marked as completed

VERIFIED:
---------
✅ Prefix check now handles both daily-streak- and daily-challenge-
✅ Challenge ID extraction works for both prefixes
✅ Proper routing to /api/daily-challenge/complete endpoint
✅ Backward compatible with any future daily-challenge- prefixed IDs

RESULT:
-------
✅ Daily-streak challenges now submit successfully
✅ No more 404 errors on module submission
✅ XP properly awarded for daily challenges
✅ Challenge completion properly recorded

LESSON LEARNED:
---------------
- Module identifier prefixes must match across the entire flow:
  1. Page/component generates the moduleId with prefix

- Check for all possible prefixes, not just one convention
